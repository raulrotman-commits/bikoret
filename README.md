# ביקורת שטח — רוטמן בטיחות

אפליקציה לדוח ביקור בטיחות באתר בנייה. כל ממצא נבחר ממאגר ליקויים לפי התקנות ומקבל הערכת סיכון (סבירות × חומרה). אפשר להוסיף לו תמונות, מיקום והערה. הדוח יוצא ממותג עם פרטי עורך הדוח, ונשלח בקישור או כ-PDF.

## מה יש בה

- **מאגר 800 ליקויים** (המאגר של ראול). לכל ליקוי שם התקנות המלא, ול-698 מהם גם מספר תקנה שנבדק מול הנוסח המשולב של התקנות (ויקיטקסט, מעודכן לתיקון 16.10.2026). מספר תקנה מודפס בדוח רק אם נבדק.
- **הערכת סיכון** במטריצה 4×4. הספים של "סיכון שאינו קביל" ו"דורש אישור בעל הסמכות" נקבעים לכל אתר לפי תכנית הבטיחות שלו (ברירת מחדל: 12 ומעלה / 4–9).
- **סיכון שאינו קביל** מופיע ראשון בדוח, עם יעד "מיידי" ואפשרות לסמן "העבודה הקשורה בסיכון הופסקה". אין באפליקציה "צו בטיחות", כי זו סמכות של מפקח עבודה.
- **ביקור המשך**: הממצאים הפתוחים מהביקור הקודם עוברים לביקור החדש. מסמנים "ראיתי שתוקן" רק אחרי שבדקת בעיניים. ליקוי שחוזר מסומן כ"ליקוי חוזר".
- **עבודה בלי קליטה**: כל שינוי ותמונה נשמרים במכשיר ומסונכרנים כשחוזרת הקליטה.
- **חיפוש** במאגר: במילים, לפי תחום, לפי נושא מיקוד, או מהערות שטח (גם בהכתבה). זה חיפוש מילים, לא בינה מלאכותית.
- **מיתוג לכל לקוח**: לוגו, שם החברה, צבע, ופרטי עורך הדוח. בתחתית כל דוח: "הופק באמצעות רוטמן בטיחות".
- **מנוי**: ביקורת שטח כלולה במנוי רוטמן בטיחות, בלי תשלום נפרד. הגישה נפתחת לפי מנוי פעיל באתר הראשי על אותו מייל (גם מנהל או ניסיון שם). חשבון חדש מקבל גם תקופת ניסיון כאן (ברירת מחדל 14 יום). מנהל יכול לתת גישה ידנית.

## מבנה

| תיקייה | תוכן |
|---|---|
| `client/` | React + Vite + Tailwind, ‏PWA, עברית מימין לשמאל |
| `server/` | Express + tRPC + Drizzle על MySQL; תמונות ב-S3 |
| `shared/` | המאגר (`catalog.json`), תקנות, מטריצת סיכון, טיפוסים |
| `scripts/` | בניית המאגר ומיפוי מספרי התקנות, הגירות, בדיקת קצה לקצה |
| `data/` | קובצי המקור: המאגר, הנוסח המשולב של התקנות, דוח הבדיקה של המיפוי |

הטבלאות מתחילות ב-`bk_`, וטבלת ההגירות היא `__bk_migrations`. לכן אפשר להריץ את האפליקציה על אותו MySQL של שומר תוקף בלי התנגשות.

## הרצה מקומית

```bash
pnpm install
cp .env.example .env        # למלא DATABASE_URL
pnpm db:migrate
pnpm build && pnpm start    # http://localhost:8080
```

בדיקת קצה לקצה (על מסך אייפון): `BASE=http://localhost:8080 node scripts/e2e.mjs`

## עדכון המאגר

```bash
python3 -I scripts/map_regulations.py data/src data   # מספרי תקנות + data/regmap-review.csv
python3 -I scripts/build_catalog.py data shared       # shared/catalog.json
```

`data/regmap-review.csv` מפרט את הליקויים שמספר התקנה שלהם לא אומת, ואת הסיבה לכך.

## העלאה ל-Railway (פרויקט helpful-ambition)

1. שירות חדש מהריפו הזה. פקודת הפעלה: `pnpm db:migrate && pnpm start`. בדיקת תקינות: `/healthz`.
2. משתנים: `DATABASE_URL` (הפניה ל-MySQL), `JWT_SECRET` (מחרוזת אקראית חדשה), `APP_URL=https://bikoret.rotmansafety.com`, `OWNER_EMAIL`, `S3_*` עם `S3_PREFIX=bikoret/`, `RESEND_API_KEY`, `EMAIL_FROM`, `TRIAL_DAYS`, `RS_DATABASE_URL=${{rotmansafety.DATABASE_URL}}` (קריאה בלבד מהמנויים של האתר הראשי).
3. דומיין: `bikoret.rotmansafety.com`. צריך להוסיף רשומת CNAME אצל רשם הדומיין.
4. להוסיף קישור "ביקורת שטח" בסרגל הניווט המשותף, באתר ובשומר תוקף.

## לפני שמשיקים ללקוחות

- לוודא שמנוי פעיל באתר הראשי פותח גישה כאן (מסך "מנוי" ← "כבר יש לי מנוי — לבדוק שוב").
- לעבור על `data/regmap-review.csv` (102 ליקויים בלי מספר תקנה מאומת) ולתקן במאגר.
